# Econometrics notes

**Read the blog:** https://econometricsnotes.github.io/econometrics/

A blog about the ideas behind applied econometrics, explained in plain words. Each post takes one
idea, wraps it in a small story, and runs the numbers in EViews. Every post ends with a question
for readers to think about.

## Data and EViews files

- [`downloads/blog_datasets.xlsx`](downloads/blog_datasets.xlsx) — one sheet per post, with a README sheet describing every variable
- [`downloads/blog_posts.prg`](downloads/blog_posts.prg) — EViews program that reproduces every table in the posts

To use them: save both files in the same folder, open EViews, choose **File → Open → Program**,
select `blog_posts.prg` and click **Run**.

All datasets are simulated for teaching purposes. You are welcome to use them in your own classes.
